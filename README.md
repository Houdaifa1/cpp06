## 🧠 Concepts Covered

- `static_cast` — compile-time checked conversions
- `dynamic_cast` — safe downcasting with RTTI
- `reinterpret_cast` — low-level bit reinterpretation
- `const_cast` — remove/add constness
- C-style casts vs C++ casts
